# OmniCalc - Smart Calculator & Graphing Suite

A modern, responsive, and feature-rich interactive calculator and Cartesian graph plotting web application.

## Features

- **Live Calculation Engine**: Real-time evaluation of mathematical expressions with support for algebraic, trigonometric, logarithmic, and power functions.
- **Cartesian Graph Plotter**: High-performance canvas graph plotter with automatic formula plotting, coordinate axes, grid scaling, and responsive resizing.
- **Dynamic View Modes**:
  - **Calculator View**: Focused calculator interface.
  - **Grapher View**: Expanded canvas graph exploration.
  - **Split View**: Side-by-side simultaneous calculation and live function graphing.
- **Theme Support**: Dark mode with ambient glow effects and sleek glassmorphism styling.
- **History & Memory**: Track previous calculations and recall values seamlessly.

## Tech Stack

- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Custom design system, glassmorphism, responsive flexbox & grid)
- **Vanilla JavaScript** (ES6+ modular logic and HTML5 Canvas API)

## Getting Started

Open `index.html` in any modern web browser or serve it using any local static web server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js (npx serve)
npx serve .
```
